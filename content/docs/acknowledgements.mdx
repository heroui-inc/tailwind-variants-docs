# Acknowledgements

**Tailwind Variants** is inspired by [Stitches](https://stitches.dev) and [CVA](https://github.com/joe-bell/cva).

- [**Stitches**](https://stitches.dev/) ([Modulz](https://modulz.app))

  The pioneers of the `variants` API pattern. Huge thanks to [Modulz](https://modulz.app) for creating Stitches and building such an inspiring community around it. 🙏

- [**CVA**](https://github.com/joe-bell/cva) ([Joe Bell](https://github.com/joe-bell))

  Tailwind Variants started as an extension of Joe's work on `cva` — an excellent tool for creating type-safe variants with Tailwind CSS. Huge thanks to [Joe Bell](https://github.com/joe-bell) and all [contributors](https://github.com/joe-bell/cva/graphs/contributors) for their amazing work. 🤘

- [**tailwind-merge**](https://github.com/dcastil/tailwind-merge), [**clsx**](https://github.com/lukeed/clsx), and [**cnfast**](https://github.com/aidenybai/cnfast)

  Tailwind Variants' conflict resolution logic is inspired by these projects and builds upon ideas from their amazing work. 🚀

We recommend using [CVA](https://github.com/joe-bell/cva) if you only need a lightweight solution for generating Tailwind CSS variants. Tailwind Variants provides additional features beyond CVA, which you can learn more about in our [comparison guide](https://www.tailwind-variants.org/docs/comparison).
